# Fioart's Aviamentos

Site front-end de uma loja de aviamentos e artesanato, desenvolvido em 2024.

> **Status: encerrado.** A loja foi encerrada e o projeto foi descontinuado. O site permanece publicado apenas como registro do trabalho.

## Sobre o projeto
Página única com apresentação da loja e catálogo de produtos dividido em quatro categorias: acessórios, crochê, bordado e macramê, e tricô. Cada produto tem um link "Saiba mais" para a página do fabricante.

## Funcionalidades
- Carrossel de imagens controlado por botões, feito em JavaScript.
- Catálogo de produtos organizado por categorias, com navegação por âncoras.
- Layout responsivo para computador, tablet e celular.
- Menu com linha animada ao passar o mouse.

## Tecnologias
- HTML5
- CSS3 (flexbox e media queries)
- JavaScript

## Estrutura
```
index.html
css/style.css
js/script.js
img/            imagens do carrossel e dos produtos
```

## Como visualizar
1. Baixe o repositório (Code > Download ZIP) e extraia os arquivos.
2. Abra o `index.html` no navegador.

Não é necessário instalar nada.
